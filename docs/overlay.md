# 오버레이 (src/overlay) — REQ-02, 04, 05

Mermaid가 그린 SVG 위에서 노드 위치·크기와 연결선 경로를 직접 편집한다. 클래스·시퀀스 다이어그램을 지원하며, 다이어그램 종류에 맞는 움직임을 제공한다.

## 클래스 다이어그램

| 요구사항 | 동작 |
| --- | --- |
| REQ-02 노드 드래그·크기 조절 | 노드를 끌면 이동, 클릭 후 오른쪽 아래 □ 핸들로 크기 조절 (원래 내용 크기보다 작게는 줄지 않음) |
| REQ-04 마그네틱 커넥터 | 옮긴 노드에 연결된 선의 끝점을 노드 테두리에 붙여 다시 그림 |
| REQ-05 엣지 경로 조정 | 선을 끌면 꺾임점 추가, 꺾임점 끌어 이동, 꺾임점 더블클릭으로 삭제 (선 더블클릭으로도 추가) |
| 엣지 다시 연결 | 선을 클릭하면 양 끝에 ■ 핸들, 끌어서 다른 노드에 놓으면 연결 대상이 바뀌고 Mermaid 코드의 관계 줄도 바뀜 (`SetCodeCommand`로 기록, Ctrl+Z 가능) |

- 크기 조절 시 글자 크기는 바꾸지 않는다 (REQ-06 폰트 스케일링 담당 영역). 연결 지점은 `ClassDiagramOverlay.applyNode` 주석 참고.
- 꺾임점은 `edgePaths`에 `"출발노드->도착노드#순번"` 이름으로 저장되어 코드를 고쳐도 유지된다 (REQ-03).

## 시퀀스 다이어그램

시퀀스에서는 위→아래 순서가 곧 시간 순서라, 상자를 자유롭게 옮기지 않고 시퀀스에 맞는 움직임만 제공한다.

| 동작 | 설명 |
| --- | --- |
| 참여자 좌우 이동 (REQ-02) | 위·아래 상자를 끌면 생명선과 함께 옆으로 움직임. 노트·활성 상자도 따라감 |
| 메시지 따라오기 (REQ-04) | 참여자를 옮기면 연결된 메시지 화살표가 양 끝이 생명선에 붙은 채 늘어나거나 줄어듦 |
| 메시지 간격 조정 | 메시지 화살표를 위아래로 끌어 바로 위·아래 메시지 사이에 놓으면 간격만 바뀜 |
| 메시지 순서 변경 | 다른 메시지를 넘어가면 놓일 자리에 초록 점선이 보이고, 놓으면 코드의 메시지 줄 순서가 바뀜 (`SetCodeCommand`, Ctrl+Z 한 번에 되돌림) |
| 보낸이·받는이 변경 | 메시지를 클릭하면 양 끝에 ■ 핸들, 다른 참여자 생명선에 놓으면 코드의 보낸이·받는이 이름이 바뀜 (예: `Alice->>Bob` → `Bob->>Carol`은 양 끝을 한 번씩) |

- 저장: 참여자 위치는 `nodeLayouts["seq:참여자"] = { x: 생명선 x, y: 0 }`, 메시지 간격은 `edgePaths["seq:보낸이->받는이#순번"] = [{ x: 0, y: 위아래 이동량 }]`
- 꺾임점·크기 조절은 시퀀스에 맞지 않아 제공하지 않는다. loop/alt 같은 묶음 상자는 따라 움직이지 않는다.

## core 사용 (가이드 "core 사용 규칙 1")

- 드래그 중: `model.setNodeLayout` / `model.setEdgePath`로 미리보기만 반영
- 드래그 끝: `new MoveNodeCommand(model, id, 최종위치, { prev: 시작위치 })`,
  `new SetEdgePathCommand(model, id, 최종경로, { prev: 시작경로 })`로 한 번만 기록 (처음 편집이면 `prev: undefined`)
- 연결 코드: `src/ui/App.ts`의 `overlay` 콜백(`onLayoutPreview` / `onLayoutCommit` / `onEdgePathPreview` / `onEdgePathCommit`)

## 성능·정확도 측정

기준: 노드 30개에서 드래그 평균 55fps 이상 (SRS 3.3, 잠정) / 끝점이 연결된 노드 경계에서 1px 이내 (REQ-04, 잠정)

측정 방법:
1. `npm run dev` 후 브라우저에서 `http://localhost:5173/?bench` 를 연다.
2. 툴바의 **성능 측정 (노드 30개)** 버튼을 누르고, 끝날 때까지(약 5초) 탭을 그대로 둔다.
3. 상태 표시줄에 결과가 나온다. 자세한 값은 개발자 도구(F12) 콘솔의 표로 볼 수 있다.

측정 내용: 클래스 30개·연결선 34개 다이어그램에서 노드를 무작위로 골라 무작위 방향으로 20번 끈다
(한 번에 15프레임 × 6px). 프레임 간격으로 fps를 재고, 매번 끈 뒤 그 노드에 연결된 선의 끝(화살촉 끝)이
노드 테두리에서 얼마나 떨어졌는지 잰다. 화살촉이 노드에 가려지지 않도록 선은 Mermaid처럼 화살촉 길이만큼 띄워 그리므로,
실제로 그려진 선 끝을 화살촉 길이만큼 연장한 점으로 잰다.
