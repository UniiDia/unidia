## 변경

- `RenderEngine`의 전역 초기화·고유 SVG ID·임시 컨테이너 정리, 기본 SVG text 라벨.
- `RenderScheduler`의 150ms 입력 병합과 최신 결과만 반영, 동일 코드 중복 렌더 방지.
- `SvgViewport`의 균일 확대·축소, App의 최소 배율 선택 UI 및 입력부터 화면 반영까지의 시간 표시.
- 유형 판별 테스트 20개, 스케줄러 테스트 7개, 실제 브라우저 시험 8개와 30개 노드 예제.
- `docs/development.md` 현재 상태, 연동 API, 원시 측정값과 캡처 갱신.

## 검증과 남은 항목

- 단위 테스트 37/37, 타입 검사, 프로덕션 빌드 통과.
- 브라우저 기능 시험 6/6 통과. 폰트 비율 변화 0%, 넘침 0px (25~400%, 제공 예제).
- 성능 시험은 **시퀀스 통과 / 클래스 실패**. Chrome 157, 노드 30개·관계 29개,
  20회 실제 코드 변경에서 p95는 시퀀스 395.5ms, 클래스 1,438.7ms입니다.
- 클래스의 1초 성능 기준은 아직 미달입니다. 이 항목을 해결하거나 팀이 범위를 결정하기 전에는
  렌더링 요구사항 전체가 완료되었다고 판단하지 않습니다.
- GUI 노드 편집·리사이즈 및 `feature/core` 통합은 별도 작업입니다.
