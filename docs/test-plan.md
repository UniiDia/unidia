# 요구사항별 테스트 계획

요구사항(REQ)마다 **어떻게 검증하는지**를 정리한다. 자동 테스트는 `npm test`로, 브라우저가 필요한 항목은 Playwright 시험(`npm run test:browser`, `npm run test:performance`)이나 직접 확인으로 검증하고, 측정 결과는 숫자로 기록한다. RQ 열은 Notion의 RQ 트래커 번호이며 RQ ↔ REQ ↔ 테스트가 이어지도록 했다.

- 기준: 2026-11-25, `main` (PR #8까지 합침)
- 자동 테스트: 150개 (core 19, overlay 50, export 37, render 27, ui 17). 11/24에 로컬에서 150개 통과를 확인했고, 11/25 PR #8로 UI 테스트가 추가되었다.
- 브라우저 시험: 14개 중 13개 통과, 1개는 환경 변수가 있을 때만 도는 선택 시험 (11/24 확인)
- 모든 PR은 `npm test`와 `npm run typecheck`가 통과해야 한다.
- 상태: ✅ 자동 테스트나 측정 기록이 있음 · 🟡 구현됐으나 검증 기록이 부족함
